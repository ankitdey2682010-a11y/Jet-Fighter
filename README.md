# Astro Firefighter

A game made in HTML CSS and Javascript

##  About the Project
Astro Firefighter is a browser game . In this game, players pilot an  starship tasked with clearing space stations ofthermal automata across 15 escalating sectors.

## Control Guide
1. **Move Ship:** `W`, `A`, `S`, `D` or `Arrow Keys`
2. **Cannon:** `Spacebar` *(Hold to shoot, watch heat meter!)*
3. **Hydro-Dash:** `Left Shift` or `Right Shift`
4. **Hydro-Bomb:** `E` Key *(Screen clearer, limited uses per sector)*
